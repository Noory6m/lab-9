# lab-9

Key Points
Goal: Classify if a borrower will pay back their loan in full.

EDA: Explored correlations between FICO scores, interest rates, and loan purposes.

Models: Compared Decision Tree vs. Random Forest (600 trees) classifiers.

Result: Random Forest achieved higher accuracy (85%), while the Decision Tree was more sensitive to high-risk borrowers.

🛠️ Tech Stack
Python: Pandas, NumPy

ML: Scikit-Learn (Decision Trees, Random Forests)

Viz: Matplotlib, Seaborn
